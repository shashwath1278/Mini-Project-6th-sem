## 1. Executive summary

This project builds a **PAZy-centered plastic-degrading enzyme discovery baseline**:

1. **Curated positives** from PAZy (and optional PlasticDB merge paths elsewhere in the repo).
2. **BLAST-based expansion** of the positive pool against external FASTA libraries under strict **90% identity / 90% query coverage** filters, with a JSON audit log.
3. **Merge + sequence-level deduplication** so the classifier trains on **unique protein sequences** (not redundant IDs that map to the same ESM-2 embedding).
4. **Homology-aware train/test split** (MMseqs2 via WSL on this machine) so **no cluster** is split across train and test; plus an optional **Silver / prior-test-Gold leakage rule** that forces whole clusters to test when needed.
5. **Frozen ESM-2 (650M, layer 33 mean-pool) embeddings** + **sklearn heads**; **v2** adds **tier-weighted training** (Gold weight 1.0, Silver 0.5 on positives after class-balanced weights).
6. **Phase-4 stress test:** reviewed **EC 3.1.1 / 3.1.2** Swiss-Prot hydrolases as **hard negatives**, scored with the **same frozen RF threshold** as training (no probe tuning).
7. **Manuscript bundle:** alias table + copied JSON/CSV + auto-generated discussion snippets for the write-up.

**Honest headline:** the primary test benchmark shows **very high (effectively saturated) ranking metrics** for the frozen-embedding + RF pipeline, which is **expected** when negatives are broad Swiss-Prot “easy negatives.” The hard-negative probe is the main counter-evidence that the model is not blindly calling every hydrolase a polyester enzyme at the operating threshold.

## 9. Integrity / limitations (what to say honestly)

1. **Primary benchmark separability:** near-perfect PR/ROC on easy negatives is **not** a demonstration of real-world deployment performance; it is primarily evidence that **ESM-2 embeddings separate your positive distribution from this negative sampling protocol**.
2. **Hard negatives are closer but still not “polyester negatives”:** EC 3.1.1/3.1.2 hydrolases are a **harder sanity check** than random Swiss-Prot, but they are **not guaranteed** to be mechanistically similar confounders for every polyester enzyme class.
3. **Homology split reduces leakage but does not erase all biology:** remote functional similarity can exist below clustering identity.
4. **Silver tier is homology-propagated:** scientifically useful for coverage, but not equivalent to PAZy curation; v2 down-weights Silver in training.
5. **Threshold behavior:** metrics are reported at a **train-chosen** recall-oriented threshold; changing the recall target changes the operating point.
